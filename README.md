🧮 BMI Calculator
A simple BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.
It calculates BMI based on user’s height and weight and shows the health category.

✨ Features
User-friendly interface

Instant BMI calculation

Shows health status:

Underweight

Normal

Overweight

Obesity

Extremely Obese

Works with Enter key

Input fields auto-clear after calculation

No external libraries

⚙️ How It Works
BMI Formula used:

BMI = Weight (kg) / (Height (m) × Height (m))
Example:

Height: 170 cm

Weight: 65 kg

BMI = 22.49 → Normal

📸 UI Description
Centered card layout

Background image

Input fields for height & weight

Button to calculate

Result shown with color:

Green → Normal

Red → Others

⚙️ How to Run
Download or clone the project.

Make sure OIP.jpg is in the same folder.

Open index.html in browser.

Enter height (cm) and weight (kg).

Press Calculate BMI or hit Enter.
